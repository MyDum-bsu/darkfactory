# Устаревшие модули V2 (Foreman/Playbooks)

Wave 2.0 заменяет конвейер эпохи Foreman/Playbooks унифицированным пайплайном Board + Herdr (`--runtime hc`). Перечисленные ниже модули **deprecated**: они сохранены в репозитории для обратной совместимости и археологии контрактов, но не должны использоваться в новом коде и не являются источником новых задач.

## Deprecated-модули

| Модуль | Назначение в V2 | Статус |
|---|---|---|
| `board_pipeline/test-first-adapter.mjs` | Host-адаптер контракта Test First: красный тест-коммит / зелёный кандидат для стадий Playbooks | **Deprecated** — не использовать в новом коде |
| `board_pipeline/playbook-router.mjs` | Маршрутизатор Playbook-стадий (executor/critic/arbiter) эпохи Foreman | **Deprecated** — не использовать в новом коде |
| `board_pipeline/bb-stage-adapter.mjs` | Адаптер BB-стадий поверх транспорта песочниц V2 | **Deprecated** — не использовать в новом коде |
| `board_pipeline/stage-sandbox-transport.mjs` | Аттестованный read-only транспорт Stage-станций (landlock-ro-v1 / docker-ro-v1) | **Deprecated** — не использовать в новом коде |

Каждый из этих файлов помечен `@deprecated` JSDoc-заголовком. Поведение и экспорты не меняются: пометка носит документирующий характер, существующие детерминированные тесты продолжают выполняться через `npm test`.

## Сохранённый модуль

| Модуль | Статус |
|---|---|
| `board_pipeline/holdout-runner.mjs` | **Не deprecated.** Сохраняется для будущего контура L3 (holdout-проверки скрытыми тестами). Модуль остаётся частью действующего пайплайна и покрыт `board_pipeline/holdout-runner.test.mjs`. |

## Правила работы

1. Новые задачи и исправления не должны расширять deprecated-модули; изменения допустимы только в рамках отдельно согласованной карточки Board.
2. Ссылки на deprecated-модули из действующего кода постепенно выводятся по мере миграции на Wave 2.0; разовая заметка в коде не является допуском к изменениям вне Scope Fence.
3. `holdout-runner.mjs` не попадает под эти ограничения и развивается в обычном порядке.
