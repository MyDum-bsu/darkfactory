# ui-ux-craft — ремесло UI-реализации

## Компоновка
- Один экран — одна главная иерархия: заголовок, действие, содержимое. Вторичные
  действия визуально слабее первичного.
- Отступы из шкалы (4/8/16/24), не «на глаз»: проверь края выравнивания соседних
  блоков, там сразу видно случайные пиксели.
- Каждое интерактивное состояние реализовано: default, hover, focus-visible,
  disabled, loading. Отсутствующее состояние — находка, а не деталь.

## Контролы
- Никаких «голых» нативных контролов рядом со стилизованными: либо дизайн-система,
  либо явный сброс стилей — смесь читается как недоделка.
- Длинные списки (>7 элементов) — свёрнуты/виртуализированы/постраничны;
  бесконечная простыня — дефект, не фича.
- Пустое, ошибочное и загрузочное состояния рисуются явно; пустой div — провал.

## Данные и границы
- Реальные данные длиннее макета: проверь переполнение (длинные имена, юникод,
  нулевые/огромные числа) до выдачи.
- Точность формата: дата, валюта, единицы — по спеке карточки, не по привычке.

## Приёмка
Каждый пункт, который ты «почти» сделал, — это открытый пункт. Финальная проверка
— по скриншоту обоих вьюпортов до выдачи артефакта.
