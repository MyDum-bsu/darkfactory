# visual-rubric — рубрика визуальной проверки

## Счётчики нарушений
- `unstyledControls`: нативный вид контрола или контрол вне дизайн-системы.
- `uncollapsedLongLists`: список >7 элементов без свёртки/пагинации/виртуализации.
- `missingStates`: обязательное состояние (empty/loading/error/disabled/focus)
  не отрисовано на снимках.
- `consoleErrors`, `a11yViolations`: любая запись — блокер.
- `holdoutFailures`: провал на holdout-сценарии рубрики.

## Процедура
1. Каждый вьюпорт (≥2) — отдельный проход: структура, выравнивание, контраст.
2. Для каждого контрола на снимке ответь: стилизован? все состояния? фокус
   виден? Нет ответа — состояние считается пропущенным.
3. Балл satisfactionScore = взвешенная доля пройденных пунктов рубрики ×100;
   балл ниже 85 — rework независимо от отсутствия блокеров.

## Честность
Не округляй «в целом хорошо» в 85+: балл складывается из пунктов, каждый с
указанием снимка и области. Пункт без привязки к снимку не засчитывается.
